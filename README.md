# StateEra — Global PropTech & Fractional Real Estate Platform

StateEra is an approval-ready, institutional-grade, AI-powered fractional real estate co-ownership and rental yield platform. It empowers international investors to co-own verified Grade-A commercial buildings and luxury residential assets across **19+ countries** starting from \$25, collect automated monthly tenant rental payouts, inspect immutable digital Property Passports, and simulate investment scenarios with full transparency.

## 📊 Section 16: Graphical Profit & Loss Analytics Suite (`/reports`)

Fully responsive, interactive Recharts dashboard:
1. **Profit & Loss Trajectory (Line Chart):** Cumulative realised rent and capital equity gains.
2. **Monthly Income vs. Operating Expenses (Bar Chart):** Gross rent collected vs. property bills (taxes, insurance, maintenance, management).
3. **Investment Growth Over Time (Area Chart):** Portfolio valuation curve compared against invested principal.
4. **Actual vs. Projected Returns (Comparison Chart):** Honest tracking of forecast accuracy across holdings.
5. **Portfolio Asset Allocation (Donut/Pie Chart):** Weighting across active properties.
6. **Country-Wise Spread (Horizontal Bar Chart):** Capital deployed across sovereign jurisdictions.
7. **Property-Wise Line-Item Accounting Table:** Shares, cost basis, current value, unrealised capital gain, and net yield.
8. **Summary Metric Cards:** Total Investment, Current Estimated Portfolio Value, Realised Rental Cashflow, Expenses & Fees, Net Rental Cashflow, and Total Net P&L.

## 🚀 Running the Project

### Prerequisites
- Node.js 18+ (Tested on Node 20 / 24)
- npm or yarn

### Development Server
```bash
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.

### Production Build Verification
```bash
npm run build
```
Compiles 35 static routes with 0 TypeScript or ESLint errors.
